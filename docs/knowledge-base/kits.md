# Kits

## What is Kits?

Kits are pre-defined bundles of items that your essentials bank frequently gives out together. For example, a "Newborn Kit" might contain diapers, wipes, and diaper cream. Instead of selecting each item individually every time, you can use a kit to quickly add the entire bundle to a distribution or other transaction.

## Key Capabilities

- Create kit templates that define a fixed set of items and quantities
- Allocate kits to storage locations, which reserves the individual items from inventory
- Deallocate kits from storage locations to release items back to general inventory
- Use kits in distributions just like individual items
- View which kits are allocated at each storage location
- Deactivate kits you no longer use

## How It Works

1. Navigate to Kits from the main menu.
2. Click "New Kit" to create a kit template.
3. Give the kit a name (for example, "Newborn Starter Kit").
4. Add the items and quantities that make up the kit (for example, 24 newborn diapers + 1 pack of wipes + 1 diaper cream).
5. Save the kit template.
6. To make kits available at a storage location, allocate them. This tells the system to set aside the component items from that location's inventory.
7. When creating a distribution, you can select the kit as a single line item instead of adding each component separately.
8. To release the reserved items back to general inventory, deallocate the kit.

## Common Questions

**Q: What is the difference between a kit template and an allocated kit?**
A: A kit template defines what items and quantities make up the kit. Allocating a kit to a storage location actually sets aside those items from inventory, making them available to distribute as a kit.

**Q: What happens to inventory when I allocate a kit?**
A: The individual items in the kit are deducted from the storage location's general inventory and reserved as kit inventory. The total items at the location stay the same -- they are just categorized differently.

**Q: Can I change what is in a kit after creating it?**
A: You can edit a kit's contents, but changes may affect allocated kits at storage locations.

**Q: How do kits appear in reports?**
A: When kits are distributed, the individual items within the kit are counted in reports. For example, a "Newborn Kit" containing 24 diapers will add 24 to the diaper distribution count in reports.

**Q: Can I allocate the same kit to multiple storage locations?**
A: Yes. You can allocate kits to any storage location that has enough of the component items in stock.

## Tips & Best Practices

- Create kits for your most commonly distributed bundles to save time during distributions.
- Verify storage location inventory before allocating kits to ensure all component items are available.
- Keep kit definitions simple and consistent so staff understand what each kit contains.

## Limitations & Important Notes

- Allocating a kit requires the storage location to have enough of each component item in stock.
- Kit contents are expanded to individual items in reports, which affects category totals.
- Changes to a kit template do not automatically update kits that have already been allocated.

## Related Features

- **Items** -- Kits are composed of items from your catalog
- **Storage Locations** -- Kits are allocated to and deallocated from specific storage locations
- **Distributions** -- Kits can be distributed to partners as a single line item
- **Reports** -- Kit items are counted individually in annual and summary reports
