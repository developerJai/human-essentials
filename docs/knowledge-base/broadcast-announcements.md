# Broadcast Announcements

## What is Broadcast Announcements?

Broadcast Announcements lets super admins and organization admins post important messages that appear on user dashboards. These announcements help communicate urgent updates, policy changes, or reminders to all users in an organization or across the entire platform.

## Key Capabilities

- Create announcements that appear on user dashboards
- Two types of announcements: system-wide (visible to all organizations) and organization-specific
- Super admins can create system-wide announcements
- Organization admins can create announcements for their own organization
- Announcements display prominently on the dashboard when users log in

## How It Works

1. A super admin or organization admin creates a new announcement.
2. The admin writes the announcement message and selects whether it is system-wide or organization-specific.
3. The announcement is saved and immediately appears on the relevant dashboards.
4. Users see the announcement when they log in or visit their dashboard.
5. Announcements can be updated or removed by the admin who created them.

## Common Questions

**Q: Who can create announcements?**
A: Super admins can create system-wide announcements visible to everyone. Organization admins can create announcements visible only to users in their organization.

**Q: Where do announcements appear?**
A: Announcements appear on the dashboard, which is the first page users see after logging in.

**Q: Can regular users create announcements?**
A: No. Only super admins and organization admins can create announcements.

**Q: How do I remove an old announcement?**
A: The admin who created the announcement can delete it from the announcements management area.

**Q: Can I target an announcement to specific users?**
A: Announcements are shown to all users in an organization (or all users platform-wide for system announcements). You cannot target individual users.

## Tips & Best Practices

- Keep announcements brief and to the point so users read them.
- Remove outdated announcements promptly to avoid clutter on the dashboard.
- Use announcements for time-sensitive information like holiday closures, supply drives, or policy changes.

## Limitations & Important Notes

- Announcements cannot be targeted to specific individual users -- they are shown to everyone in the relevant scope.
- There is no scheduling feature; announcements appear immediately upon creation.
- Regular users and partners cannot create or manage announcements.

## Related Features

- **Dashboard** -- Announcements are displayed on the dashboard
- **Admin Panel** -- Super admins manage system-wide announcements
- **Organizations** -- Organization-level announcements are scoped to a single organization
