# Distributions

## What is Distributions?

Distributions represent outgoing supplies that your essentials bank sends to partner organizations. Each distribution records what items were sent, how many, from which storage location, to which partner, and when. Distributions are the core way your bank fulfills partner requests and gets supplies to the families who need them.

## Key Capabilities

- Create distributions to send supplies to partners
- Choose items and quantities from a specific storage location
- Multiple delivery methods: pick up, delivery, or shipped
- Generate a PDF packing slip (manifest) for each distribution
- View distributions on a calendar by scheduled date
- Filter and search past distributions by partner, storage location, item, or date range
- Fulfill partner requests directly by starting a distribution from a request
- Automatic email reminders to partners about upcoming distributions
- Export distribution data to CSV

## How It Works

1. Navigate to Distributions and click "New Distribution."
2. Select the partner receiving the supplies.
3. Choose the storage location the items will come from.
4. Add items and quantities to the distribution.
5. Select the delivery method (pick up, delivery, or shipped) and set the date.
6. Save the distribution.
7. The system deducts the distributed items from the storage location's inventory.
8. You can print a PDF packing slip to include with the shipment.
9. If the distribution was created from a partner request, the request is automatically marked as fulfilled.

## Common Questions

**Q: Can I create a distribution directly from a partner request?**
A: Yes. From the Requests page, click "Fulfill Request" on a pending request. This creates a new distribution pre-filled with the requested items.

**Q: What happens to inventory when I create a distribution?**
A: The quantities are automatically subtracted from the selected storage location's inventory.

**Q: Can I edit a distribution after creating it?**
A: Yes, you can edit a distribution to change items or quantities. The inventory adjustments are updated accordingly. However, editing may be restricted if an inventory snapshot has been taken since the distribution was created.

**Q: Can I delete a distribution?**
A: Only organization admins can delete distributions. Deletion is blocked if an inventory snapshot has been taken since the distribution was created.

**Q: What is the distribution calendar?**
A: The calendar view shows all scheduled distributions by date, making it easy to see upcoming deliveries and plan logistics.

**Q: How do distribution reminders work?**
A: The system can send automatic email reminders to partners before their scheduled distribution date, based on your organization's reminder settings.

**Q: Can I print a packing slip?**
A: Yes. Each distribution has a "Print" option that generates a PDF packing slip listing all items and quantities.

## Tips & Best Practices

- Always verify the storage location has enough inventory before creating a distribution.
- Use the "Fulfill Request" flow when possible to ensure partner requests are properly tracked and closed.
- Print packing slips and include them with shipments for partner verification.
- Set up distribution reminders to keep partners informed.
- Review the distribution calendar weekly to plan logistics and staffing.

## Limitations & Important Notes

- A distribution cannot be created if the storage location does not have enough of the requested items.
- Distributions linked to inventory snapshots cannot be edited or deleted.
- Only organization admins can delete distributions. Regular users can create and edit them.
- Each distribution is tied to a single storage location. To send items from multiple locations, create separate distributions.

## Related Features

- **Requests** -- Partner requests can be fulfilled by creating a distribution
- **Storage Locations** -- Items are drawn from a specific storage location
- **Partners** -- Each distribution is sent to a specific partner
- **Items** -- Distributions contain line items from your item catalog
- **Inventory Events** -- Distributions update inventory through the tracking system
- **Reports** -- Distribution data feeds into summary and annual reports
