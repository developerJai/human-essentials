# Items

## What is Items?

Items are the supply types that your essentials bank manages -- things like diapers (various sizes), wipes, period supplies, adult incontinence products, and other essentials. The Items feature lets you set up and maintain your organization's catalog of everything you track, distribute, and receive.

## Key Capabilities

- Create and manage your organization's catalog of supply types
- Organize items into categories (for example, Diapers, Period Supplies, Adult Incontinence, Other)
- Set minimum and recommended on-hand quantities for low inventory alerts
- Define custom request units (for example, "packs" or "boxes") that partners can use when making requests
- Deactivate items you no longer carry (without losing historical data)
- Reactivate previously deactivated items
- View current inventory levels per item across all storage locations
- Items are based on the platform's master list (base items) managed by super admins

## How It Works

1. Navigate to Items from the main menu.
2. Your organization's item catalog is displayed, showing each item with its current inventory.
3. To add a new item, click "New Item" and select from the available base item types.
4. Set the item's name, category, and optional fields like minimum quantity or custom request unit.
5. Save the item. It is now available for use in donations, distributions, purchases, and other transactions.
6. If you stop carrying an item, deactivate it. It will no longer appear in dropdown lists for new transactions but will remain in historical records.
7. Reactivate a deactivated item if you start carrying it again.

## Common Questions

**Q: What is a base item?**
A: Base items are the master list of supply types defined by platform super admins. Your organization creates its own items based on these base items. This ensures consistency across the platform while letting each organization customize names and settings.

**Q: What are item categories?**
A: Categories group related items together (for example, all diaper sizes under "Diapers"). Categories help organize your catalog and are used in reporting.

**Q: What is a reporting category?**
A: Reporting categories determine how items are classified in annual reports (for example, "Disposable Diapers," "Period Supplies," "Adult Incontinence"). This affects how totals appear in your NDBN annual report.

**Q: What happens when I deactivate an item?**
A: The item is hidden from dropdown lists in new transactions, but all historical records involving that item are preserved. You can reactivate it at any time.

**Q: What are custom request units?**
A: Custom request units let you define alternative ways partners can request items. For example, instead of requesting 24 individual diapers, a partner could request 1 "case" of diapers. You define what units are available for each item.

**Q: Can I set low inventory thresholds?**
A: Yes. You can set a minimum on-hand quantity and a recommended quantity for each item. When inventory falls below these levels, alerts appear on the dashboard.

## Tips & Best Practices

- Set minimum and recommended quantities for your most critical items to get timely low-stock alerts.
- Use meaningful names so all staff can easily identify items.
- Deactivate seasonal or discontinued items instead of deleting them to preserve historical data.
- Review your item catalog periodically to ensure it stays current.

## Limitations & Important Notes

- Items are based on base items defined by super admins. You cannot create entirely custom item types outside the base item list.
- Deactivated items remain in historical records but are hidden from new transactions.
- Changing an item's reporting category affects how it appears in annual reports.
