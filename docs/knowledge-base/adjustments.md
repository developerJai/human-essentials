# Adjustments

## What is Adjustments?

Adjustments let you manually correct inventory quantities at a specific storage location. If your actual stock does not match what the system shows, you can create an adjustment to increase or decrease item counts to reflect reality.

## Key Capabilities

- Add or subtract inventory for one or more items at a storage location
- Attach a comment explaining the reason for the adjustment
- View a history of all adjustments with filters by storage location
- Each adjustment is permanently recorded and cannot be edited or deleted after creation

## How It Works

1. Navigate to the Adjustments section from the main menu.
2. Click "New Adjustment."
3. Select the storage location where the correction is needed.
4. Add items and specify the quantity change (positive to add, negative to subtract).
5. Provide a comment explaining why the adjustment is needed (for example, "Found extra box during cleanup").
6. Submit the adjustment.
7. The system updates the inventory at that storage location immediately.

## Common Questions

**Q: When should I use an adjustment?**
A: Use adjustments when the system's inventory count does not match the physical count and you need a quick correction. Common reasons include damaged goods, miscounts, or items found during cleanup.

**Q: Can I edit or delete an adjustment after creating it?**
A: No. Adjustments are permanent once created. If you made an error, create a new adjustment to correct it.

**Q: Can I adjust multiple items at once?**
A: Yes. A single adjustment can include changes to multiple items at the same storage location.

**Q: What is the difference between an adjustment and an audit?**
A: An adjustment is a quick manual correction. An audit is a formal process where you count everything at a location and reconcile the totals. Audits have a multi-step workflow (in progress, confirmed, finalized), while adjustments take effect immediately.

**Q: Who can create adjustments?**
A: Any user with access to your organization can create adjustments.

**Q: Does the adjustment show who made it?**
A: Yes. Each adjustment records the user who created it.

## Tips & Best Practices

- Always include a meaningful comment so others understand why the adjustment was made.
- Use adjustments for small corrections. For a full inventory recount, use the Audits feature instead.
- Review adjustment history periodically to spot patterns like frequent shrinkage at certain locations.

## Limitations & Important Notes

- Adjustments cannot be edited or deleted after creation.
- Each adjustment applies to only one storage location. To correct inventory at multiple locations, create separate adjustments.
- Adjustments that would result in negative inventory at a location are not allowed.

## Related Features

- **Audits** -- For formal, multi-step physical inventory verification
- **Storage Locations** -- Adjustments are always tied to a specific storage location
- **Inventory Events** -- Adjustments feed into the inventory tracking system
- **Transfers** -- Use transfers instead if you need to move items between locations
