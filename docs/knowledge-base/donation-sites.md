# Donation Sites

## What is Donation Sites?

Donation Sites are physical locations where community members can drop off donated supplies for your essentials bank. These could be churches, community centers, businesses, or any other locations that serve as collection points.

## Key Capabilities

- Create and manage a list of donation drop-off locations
- Record contact information and address for each site
- Link donations to the site where they were collected
- Deactivate sites that are no longer in use (without losing historical data)
- Reactivate previously deactivated sites
- View donation history per site

## How It Works

1. Navigate to Donation Sites from the main menu.
2. Click "New Donation Site" to add a location.
3. Enter the site name, address, and contact information.
4. Save the site. It is now available as an option when recording donations.
5. When recording a new donation, you can select this site as the source.
6. If a site is no longer active, deactivate it. Deactivated sites do not appear in dropdown lists for new donations, but all past donation records remain intact.
7. If a site becomes active again, you can reactivate it.

## Common Questions

**Q: What happens when I deactivate a donation site?**
A: The site no longer appears as an option when recording new donations, but all historical donations linked to that site are preserved.

**Q: Can I delete a donation site?**
A: You can delete a donation site only if it has no donations associated with it. If donations exist, use the deactivate option instead.

**Q: How do donation sites differ from storage locations?**
A: Donation sites are where the public drops off donations. Storage locations are where your organization keeps its inventory. Donations collected at a site are recorded and added to a storage location's inventory.

**Q: Can I see how many donations a site has received?**
A: Yes. The site detail page shows a history of all donations linked to that site.

**Q: Can I import donation sites from a spreadsheet?**
A: Yes. You can import donation sites in bulk using a CSV file.

## Tips & Best Practices

- Keep donation site information up to date so volunteers and donors can find them easily.
- Deactivate seasonal or temporary sites after their collection period ends rather than deleting them.
- Review your donation site list periodically to remove outdated entries.

## Limitations & Important Notes

- Donation sites with existing donations cannot be deleted -- use deactivation instead.
- Deactivated sites are hidden from new donation forms but remain in the system for historical reference.
- Donation sites are organization-specific and not shared between organizations.

## Related Features

- **Donations** -- Donations can be linked to a specific donation site
- **Storage Locations** -- Donated items are ultimately stored at a storage location
- **Product Drives** -- Community donation campaigns may use donation sites as collection points
