# Admin Panel

## What is the Admin Panel?

The Admin Panel is a special area of Human Essentials reserved for platform-level super administrators. It provides tools to manage organizations, users across the entire platform, global item definitions, barcodes, and FAQ content.

## Key Capabilities

- View and manage all organizations on the platform
- Create, edit, and deactivate user accounts across all organizations
- Manage base items (the master list of item types available to all organizations)
- Manage global barcode mappings shared across the platform
- Manage NDBN (National Diaper Bank Network) member listings
- Create and edit FAQ questions that appear on the help page
- View the platform dashboard with overall statistics
- Review and approve or reject account requests from new organizations

## How It Works

1. Log in as a super admin.
2. You are directed to the Admin Dashboard, which shows platform-wide statistics.
3. From the admin menu, navigate to the area you need:
   - **Organizations** to view, edit, or manage any organization's settings
   - **Users** to search for, create, or manage user accounts
   - **Base Items** to add or update the master list of supply types
   - **Barcode Items** to manage global barcode-to-item mappings
   - **Account Requests** to approve or reject new organization applications
   - **FAQ** to add or edit questions shown on the help page
4. Make your changes and save.

## Common Questions

**Q: Who can access the Admin Panel?**
A: Only super admins have access. Organization admins and regular users cannot see or use the Admin Panel.

**Q: What are base items?**
A: Base items are the global master list of supply types (like "Diapers - Size 3" or "Wipes"). Organizations choose from base items to build their own item catalog. Changes to base items can affect all organizations.

**Q: Can I manage a specific organization's settings from the Admin Panel?**
A: Yes. You can view and edit any organization's details, including their name, contact information, and partner settings.

**Q: What happens when I deactivate a user from the Admin Panel?**
A: The user can no longer log in, but their historical activity (like donations and distributions they recorded) is preserved.

**Q: How do FAQ entries work?**
A: You create questions and answers in the Admin Panel. These appear on the Help page that all logged-in users can access. Users can search the FAQ by keyword.

**Q: Can I add or remove roles for a user?**
A: Yes. From the Admin Panel user management section, you can assign or remove roles for any user, including granting admin access to specific organizations.

## Tips & Best Practices

- Review account requests regularly so new organizations are not kept waiting.
- Keep base items well-organized since they form the foundation of every organization's item catalog.
- Write clear, concise FAQ answers to reduce support requests.
- Be careful when deactivating users -- make sure the organization has at least one other admin.

## Limitations & Important Notes

- Only super admins can access the Admin Panel. There is no way to grant partial admin access.
- Changes to base items affect the options available to all organizations.
- Deleting a user or organization can have cascading effects on historical data.

## Related Features

- **Account Requests** -- New organization applications are reviewed here
- **Organizations** -- Organization settings can be managed from the Admin Panel
- **Users & Authentication** -- User accounts and roles are managed here
- **Items** -- Base items defined here become available to organizations
- **Barcode Items** -- Global barcodes are managed from the Admin Panel
