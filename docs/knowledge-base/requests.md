# Requests

## What is Requests?

Requests are supply orders submitted by partner agencies to your essentials bank. Partners submit requests through the Partner Portal, and your staff reviews, fulfills, or cancels them from the bank side. Requests are the bridge between what partners need and the distributions you create to meet those needs.

## Key Capabilities

- View all incoming partner requests with filters by partner, item, status, request type, and date range
- See request details with current inventory levels to help with fulfillment decisions
- Start fulfilling a request, which creates a distribution pre-filled with the requested items
- Cancel a request with a reason (the partner is automatically notified by email)
- Print picklist PDFs for individual requests or all unfulfilled requests
- Export request data to CSV
- View aggregated product totals across multiple requests
- Track request status: pending, started, fulfilled, or cancelled
- Support for three request types: quantity-based, individual, and child-based

## How It Works

1. A partner submits a request through the Partner Portal.
2. The request appears on your Requests page with "Pending" status.
3. Review the request details, including what items are requested and current inventory levels.
4. To fulfill the request:
   - Click "Fulfill Request." The status changes to "Started."
   - You are taken to a new distribution form pre-filled with the requested items and partner.
   - Adjust quantities if needed, select the storage location, and save the distribution.
   - The request is automatically marked as "Fulfilled."
5. To cancel the request:
   - Click "Cancel" and provide a reason.
   - The partner receives an email notification explaining why the request was cancelled.
6. You can print a picklist PDF to help warehouse staff pick and pack the items.

## Common Questions

**Q: What are the different request statuses?**
A: Pending (waiting for review), Started (fulfillment in progress), Fulfilled (distribution created), and Cancelled (request was declined).

**Q: Can partners edit a request after submitting it?**
A: No. Once submitted, the request cannot be edited by the partner. If changes are needed, the bank should cancel the request and ask the partner to submit a new one.

**Q: What is a picklist?**
A: A picklist is a printable PDF document listing the items and quantities for a request. Warehouse staff use it to pick items from shelves before packing and distributing.

**Q: Can I see how much inventory is available for a requested item?**
A: Yes. The request detail page shows current on-hand quantities for each requested item, both overall and at specific storage locations.

**Q: What is a partner quota?**
A: A quota is an optional limit on how many items a partner can request. When set, the system highlights when requests approach or exceed the quota.

**Q: Can I fulfill multiple requests at once?**
A: Each request is fulfilled individually by creating a separate distribution. However, you can print a combined picklist for all unfulfilled requests to help with batch picking.

**Q: What happens when I cancel a request?**
A: The request is marked as cancelled, and the partner receives an email notification with the reason you provided. Cancelled requests cannot be reopened.

## Tips & Best Practices

- Review pending requests regularly to avoid long wait times for partners.
- Use the picklist PDF to improve warehouse efficiency when preparing orders.
- Check inventory levels before starting fulfillment to ensure you have enough stock.
- Provide a clear reason when cancelling a request so the partner understands why.
- Use the product totals feature to see aggregate demand across multiple requests for purchasing decisions.

## Limitations & Important Notes

- Once a request is fulfilled, its status cannot be changed.
- Cancelled requests cannot be reopened -- a new request must be submitted.
- Partners cannot edit requests after submission.
- Each request is fulfilled through a single distribution from one storage location.

## Related Features

- **Partner Portal** -- Where partners submit their supply requests
- **Distributions** -- Fulfilling a request creates a distribution
- **Partners** -- Each request is associated with a specific partner
- **Items** -- Requested items come from your item catalog
- **Storage Locations** -- Inventory availability is checked per storage location during fulfillment
