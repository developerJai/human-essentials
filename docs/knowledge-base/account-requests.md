# Account Requests

## What is Account Requests?

Account Requests lets new organizations (essentials banks) apply to join the Human Essentials platform. Prospective organizations fill out a public registration form, and a super admin reviews, approves, or rejects each application.

## Key Capabilities

- Public registration form for new organizations wanting to join the platform
- Email confirmation sent to the applicant after submitting a request
- Super admin review queue to approve or reject pending requests
- Automatic organization and admin user setup upon approval
- Rejection notification sent by email when a request is declined
- Request details include organization name, email, and website

## How It Works

1. A prospective organization visits the public landing page and clicks "Request An Account."
2. They fill in their organization name, contact email, and other basic details.
3. After submitting, they receive an email confirming their request was received.
4. A super admin sees the new request in the admin panel under Account Requests.
5. The super admin reviews the details and chooses to approve or reject the request.
6. If approved, the system creates a new organization and sets up the requester as its first admin user. An approval email is sent.
7. If rejected, the requester receives a rejection email explaining the outcome.

## Common Questions

**Q: Who can submit an account request?**
A: Anyone can submit a request. The registration form is publicly accessible and does not require an existing account.

**Q: How long does it take for a request to be reviewed?**
A: It depends on how quickly a super admin reviews pending requests. There is no automatic approval -- a human must review and approve each one.

**Q: What happens after my request is approved?**
A: A new organization is created for you, and you are set up as the organization admin. You will receive an email with instructions to log in.

**Q: Can I resubmit if my request is rejected?**
A: Yes, you can submit a new request from the registration page at any time.

**Q: Who reviews account requests?**
A: Only super admins (platform-level administrators) can approve or reject account requests.

**Q: Will I be notified about the status of my request?**
A: Yes. You receive a confirmation email when you submit, and another email when your request is approved or rejected.

## Tips & Best Practices

- Make sure the email address you provide is accurate, as all notifications go to that address.
- Include your organization's website if available -- it helps admins verify your request.
- If you have not heard back after a reasonable time, contact the platform administrators directly.

## Limitations & Important Notes

- There is no way for applicants to check the status of their request online -- they must wait for the email notification.
- Only one organization is created per approved request. If your organization needs multiple accounts, each must be requested separately.
- Super admins are the only users who can manage account requests. Organization admins cannot.

## Related Features

- **Admin Panel** -- Where super admins review and manage account requests
- **Users & Authentication** -- The approved requester becomes the first user and admin of the new organization
- **Static Pages** -- The public landing page links to the account request form
