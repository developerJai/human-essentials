# Donations

## What is Donations?

Donations track all incoming supplies that your essentials bank receives from the community. Whether items come from a product drive, a manufacturer, a donation site drop-off, or a miscellaneous source, each donation is recorded with details about what was received, how much, and where it is stored.

## Key Capabilities

- Record donations from four different sources: product drives, manufacturers, donation sites, and miscellaneous
- Track individual items and quantities received in each donation
- Assign donated items to a specific storage location
- Filter and search donations by source, storage location, item, or date range
- Export donation data to CSV for reporting
- View recent donation history and totals
- Each donation updates inventory automatically at the assigned storage location

## How It Works

1. Navigate to Donations and click "New Donation."
2. Select the source of the donation:
   - **Product Drive** if the items came from a community collection campaign
   - **Manufacturer** if a company donated the supplies
   - **Donation Site** if items were collected at a drop-off location
   - **Miscellaneous** for any other source
3. Choose the storage location where the donated items will be stored.
4. Add items and their quantities.
5. Set the date the donation was received.
6. Save the donation.
7. The system automatically adds the donated items to the selected storage location's inventory.

## Common Questions

**Q: What are the different donation sources?**
A: There are four sources: Product Drives (community campaigns), Manufacturers (corporate donors), Donation Sites (drop-off locations), and Miscellaneous (everything else).

**Q: Can I edit a donation after recording it?**
A: Yes, you can edit the items and quantities. However, editing may be restricted if an inventory snapshot was taken after the donation was created.

**Q: Can I delete a donation?**
A: Only organization admins can delete donations, and only if no inventory snapshot has occurred since the donation was recorded.

**Q: Does recording a donation automatically update inventory?**
A: Yes. When you save a donation, the items and quantities are immediately added to the selected storage location's inventory.

**Q: Can I record a donation without a specific source?**
A: Yes. Use the "Miscellaneous" source for donations that do not fit the other categories.

**Q: Can I export donation data?**
A: Yes. You can export filtered donation data to a CSV file from the donations listing page.

## Tips & Best Practices

- Always select the correct source type so your reports accurately reflect where donations come from.
- Record donations promptly after receiving them to keep inventory counts accurate.
- Use filters to review donations by source or time period for reporting.
- Link donations to product drives when applicable so drive performance can be tracked.

## Limitations & Important Notes

- Donations tied to inventory snapshots cannot be edited or deleted.
- Only organization admins can delete donations.
- Each donation is assigned to one storage location. If a single delivery goes to multiple locations, create separate donation records.

## Related Features
