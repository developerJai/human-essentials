# Partner Groups

## What is Partner Groups?

Partner Groups let you organize your partner agencies into groups and apply shared settings. Groups are useful for controlling which items partners can request and setting up reminder schedules. For example, you might have groups like "Food Pantries," "Shelters," or "Family Service Agencies," each with different item access and reminder timing.

## Key Capabilities

- Create named groups to organize partner agencies
- Restrict which item categories partners in a group can request
- Set reminder schedules per group for distribution reminders
- Assign partners to groups
- One partner can belong to one group at a time
- View which partners are in each group

## How It Works

1. Navigate to Partner Groups from the main menu.
2. Click "New Partner Group" to create a group.
3. Name the group (for example, "Food Pantries" or "Monthly Partners").
4. Optionally, select which item categories partners in this group are allowed to request. If no categories are selected, partners can request any item.
5. Optionally, set a reminder schedule for the group (for example, send distribution reminders 2 days before each distribution).
6. Save the group.
7. Assign partners to the group from the partner management page.
8. Partners in the group will now see only the allowed items when making requests, and they will receive reminders according to the group's schedule.

## Common Questions

**Q: Can a partner belong to more than one group?**
A: No. Each partner can belong to only one group at a time. If you need a partner in a different group, reassign them.

**Q: What happens if I do not assign a partner to any group?**
A: Partners without a group can request any item and follow the organization's default reminder schedule.

**Q: How do item restrictions work?**
A: When you set item categories on a group, partners in that group can only request items from those categories. Items outside the allowed categories will not appear in their request forms.

**Q: Can I change a group's settings after creating it?**
A: Yes. You can edit the group name, item restrictions, and reminder schedule at any time. Changes affect all partners in the group immediately.

**Q: What are reminder schedules?**
A: Reminder schedules control when automated email reminders are sent to partners about upcoming distributions or deadlines.

## Tips & Best Practices

- Use groups to simplify management of partners with similar needs.
- Name groups clearly so staff can easily understand which partners belong to each group.
- Review item restrictions periodically to ensure partners can access what they need.
- Communicate group changes to affected partners so they know what to expect.

## Limitations & Important Notes

- Each partner can belong to only one group.
- Item restrictions apply to the entire group -- you cannot customize restrictions for individual partners within a group.
- Partners not assigned to any group default to unrestricted item access.

## Related Features

- **Partners** -- Partners are assigned to groups from the partner management page
- **Items** -- Item categories are used to set request restrictions per group
- **Distributions** -- Reminder schedules affect distribution reminder timing
- **Requests** -- Item restrictions determine what partners can request
